## 정리하며 적용한 최소 수정

1. Notebook의 Colab 절대경로(`/content/...`)를 CLI 인자로 교체했습니다.
2. 실종문자 댓글 컬럼 `댓글내용`과 재난문자 컬럼 `댓글 내용`을 공통 컬럼으로 통일했습니다.
3. 원본 재난문자 분석 Notebook의 `sitive_word_df` 오타 및 정의되지 않은 `positive_word_df` 참조를 공통 키워드 함수로 대체했습니다.
4. 동일한 Okt·워드클라우드 코드를 공통 모듈로 재사용합니다.
5. 원본의 `>= 0` 긍정, `<= -20` 부정 기준을 보존했습니다. 두 범주에 속하지 않는 댓글은 `middle`로 보관합니다.
6. HTML 크롤러의 브라우저 자원 해제, 예외 메시지, CSV 인덱스 제외 등을 개선했습니다.
7. 원본 Notebook에 포함된 실행 결과와 출력 이미지·제3자 댓글 데이터는 배포 ZIP에 넣지 않았습니다.

## 자료에 없는 코드와 데이터

- YouTube 댓글의 **최초 크롤링을 실제로 수행한 코드**는 제공된 네 파일에 없습니다. 이름에 '크롤링'이 들어간 Notebook도 실제로는 이미 수집한 CSV를 읽습니다.
- `실종재난문자 유튜브 크롤링_20240725.csv`, `재난문자 뉴스 댓글 크롤링.csv`, `SentiWord_info.json`, `BMDOHYEON_ttf.ttf`, `스마일 이미지 2.png`, `bad.png`는 제공되지 않았습니다.
- 발표자료의 재난문자 비율 분석 및 개선안 제안의 **원본 계산/결론 도출 코드**는 네 파일에서 확인되지 않습니다. 본 저장소는 존재하는 코드를 기준으로 리팩터링했습니다.

> 감성분석은 사전 단어의 포함 여부로 점수를 합산하는 원본 규칙 기반 로직입니다. 머신러닝 분류기나 문맥 기반 감성분석 성능이 검증된 것처럼 소개해서는 안 됩니다.
